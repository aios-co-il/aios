# Carmen Marketing OS — approved brand assets

This directory is reserved for the **approved rendered artwork**, not CSS/SVG reconstructions.

## Expected files

- `wordmark.webp` / `wordmark.png`: standalone **Carmen Marketing OS** wordmark, with **OS tight to Marketing**, without the C icon.
- `symbol.webp` / `symbol.png`: standalone approved C + growth bars + arrow symbol.
- `magnetic-texture.webp`: decorative magnetic texture.

## Use

- Header/footer: `/brand/carmen/wordmark.webp`
- Hero: `/brand/carmen/symbol.webp` (opacity 20% when used as a subtle background, or stronger when featured)
- Decorative backgrounds: `/brand/carmen/magnetic-texture.webp`

Colors: Deep Blue #0A1526; Toxic Green #08F467; Jade #33D3A5; Emerald #E3FAE0.

**Status:** Asset exports have been prepared outside GitHub. They must be uploaded as binary files into this directory before the site is switched to them. Do not use existing `/carmen-symbol.svg` and `/carmen-wordmark.svg` as approved assets: those are inaccurate reconstructions.
