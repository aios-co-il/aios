# Code readability

- Separate imports from the declarations or executable code that follows with one blank line.
- Separate functions, types, test suites, and test cases with one blank line; keep documentation comments attached to their declaration.
- Within a function or test, use one blank line between logical steps, such as input preparation, execution, and result assertions. Keep statements that perform one step together rather than separating every statement.
- Apply spacing when adding or editing code; keep formatting changes within the requested scope.
