# AIOS Meeting Recorder — Chrome Extension

תוסף Chrome (Manifest V3) שמקליט פגישות — מסך + אודיו מערכת + מיקרופון — ומעלה אותן ישירות
לספריית ההקלטות של AIOS. לאחר ההעלאה ההקלטה מתומללת אוטומטית (Whisper), ואם שויכה ללקוח —
נוצר סיכום פגישה (DOCX שמצורף ללקוח) ובריף שיווקי (טיוטה) במחלקת השיווק.

## איך זה עובד

1. **Popup**: התחברות עם חשבון AIOS (אימייל+סיסמה) → בחירת סוג הקלטה — **פגישת וידאו** (מסך + משתתפים) או **הקלטת מסך/הדרכה** עם מצלמה אופציונלית → ארגון → לקוח (אופציונלי) → נושא → "התחל הקלטה".
   - במצב הקלטת מסך עם מצלמה: כפתור "הפעל מצלמה" פותח בועת מצלמה צפה (Picture-in-Picture, ניתנת לגרירה ושינוי גודל). הבועה נלכדת בתוך ההקלטה כשבוחרים לצלם את **המסך כולו** (Entire Screen).
2. **חלון הקלטה**: בחירת מסך/חלון/טאב (מומלץ לסמן "Share audio" כדי להקליט את משתתפי הפגישה) + מיקרופון.
3. מוקלטים **מספר מסלולים במקביל**: וידאו מלא (~1Mbps) לצפייה, ושני ערוצי אודיו נפרדים לתמלול — **מיקרופון** (המקליט) ו**אודיו מערכת** (שאר המשתתפים). ערוץ המערכת מוקלט גם כקובץ רציף אחד שנשלח ל-diarization (ElevenLabs Scribe v2) — כך התמלול מבחין **בין כל המשתתפים המרוחקים**: `[12:34] מקליט: ... / משתתף 1: ... / משתתף 2: ...`. ללא `ELEVENLABS_API_KEY` (סוד ב-Supabase) יש נסיגה אוטומטית ל-Whisper עם תווית "משתתפים" מאוחדת.
4. ערוצי התמלול מתפצלים לקטע עצמאי חדש **כל 10 דקות, והקטעים עולים לענן תוך כדי הפגישה** — קריסת דפדפן מאבדת לכל היותר את הדקות האחרונות, ואין מגבלת אורך לפגישה (כל קטע ~2.5MB, הרחק מתקרת ה-25MB של Whisper). בסוף הפגישה השרת מתמלל את כל הקטעים במקביל ומחבר לציר זמן אחד עם דוברים.
5. **שמות אמיתיים לדוברים:** התוסף דוגם צילום מסך פעם בדקה; אחרי ה-diarization השרת בוחר פריימים מרגעים שבהם כל דובר דיבר, קורא בעזרת מודל vision את תווית השם של הדובר המודגש (Zoom/Meet), ומחליף את "משתתף N" בשם האמיתי. עובד כשרשת המשתתפים נראית; בזמן שיתוף מסך אין אריחים — הדובר יישאר עם תווית מספרית. הפריימים נמחקים יחד עם ההקלטה.
6. בעצירה: העלאה ל-bucket `recordings` (נתיב `{tenant_id}/...`), רישום ב-`zoom_recordings` עם `source='chrome_extension'`, והפעלת `ingest-extension-recording` שמריצה תמלול → סיכום → בריף ברקע.
7. מצב **"אודיו בלבד"**: מדלג על הווידאו — קובץ קטן משמעותית.

ללא שיוך לקוח, העיבוד עוצר אחרי התמלול; שיוך לקוח מאוחר יותר בעמוד ההקלטות + כפתור "סכם" משלים את השרשרת.

## בנייה וטעינה (ללא Chrome Web Store)

```bash
cd extension
bun install        # או: npm install
bun run build      # או: npm run build  →  extension/dist/
```

1. פתח `chrome://extensions`
2. הפעל **Developer mode** (מצב מפתחים)
3. **Load unpacked** → בחר את התיקייה `extension/dist`
4. הצמד את התוסף לסרגל והתחבר עם חשבון ה-AIOS שלך

לאחר שינוי קוד: `bun run build` ואז ↻ (reload) בעמוד `chrome://extensions`.

## הערות

- ה-anon key של Supabase מוטמע בקוד (`src/config.ts`) — זהו מפתח ציבורי; כל הגישה נאכפת ע"י RLS עם ה-JWT של המשתמש המחובר.
- בחירת ארגון בתוסף מעדכנת את `user_active_tenant` (כמו באפליקציה) — זה נדרש כדי ש-RLS יזהה את הטננט הפעיל.
- ההקלטה נעצרת גם בלחיצה על "Stop sharing" של Chrome.
- קבצים ישנים/ידניים גדולים מ-25MB: השרת מפצל אוטומטית MP3 ו-WAV; פורמטים אחרים (m4a/webm) גדולים מדי יקבלו שגיאה ברורה עם הנחיה.
